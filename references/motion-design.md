# 让动作承担推理

用于数学、算法和机制动画。静态结构图可以静止；解释过程时，让操作在图形和表达式上实际发生。这里将 Hermes 的视觉节拍、注意力层级和联动方式，结合 CT 试制中“完整图先摆好、配音随后解释”的不足，组织为制作方法。

## 从动词得到状态变化

| 旁白中的操作 | 画面应发生什么 | 数学核对 |
|---|---|---|
| 复制、铺回、广播 | 一个取样值沿目标集合展开；源位置与目标位置同时可辨 | 每个目标取值来自同一规则 |
| 分解、分组 | 原对象拆成能重新合成的子对象 | 分量和与原对象相符 |
| 倍乘、加权、滤波 | 各分量振幅、谱线高度或对应场值随权重变化 | 共用坐标和色标；整体图形放大不代表振幅变化 |
| 换元、代入、展开 | 保留其余项，追踪被替换的语义项 | 等号两侧相位或数值含义对应 |
| 叠加、积分、累积 | 单个贡献进入部分和，显示累加前后与差值 | 计算带符号的和，不用不透明覆盖代替相加 |
| 换序、等价 | 同一输入沿两条路线执行，中间状态可见，最后对齐 | 相同输入、算子、参数和显示尺度 |
| 参数变化 | 一个控制量驱动图、数、式和响应 | 每个中间状态都满足关系 |

按当前难点选用，不要求每片包含所有方法。标题、参考图与阅读停顿不需机械动作。

## 可实现的节拍

字幕是节拍的一部分，不是整段旁白的转录块。每句字幕对应一个当前可见的变化；长句按动作依赖拆开。例如“先选位置 → 读取高度 → 沿射线复制”分别用三句字幕与三个动作，不能在第一次选位置时同时显示后两个结论。以实际场景时钟记录字幕起止与动作区间。引入新术语前，检查它是否在受众前置知识边界内。

关键节拍写清以下内容，可压缩放在现有分镜中：

```yaml
spoken_action: 对每个频率乘相应权重
source_object: 两个频率成分，振幅为 a1、a2
driver: filter_mix 从 0 变为 1
response: 曲线振幅、谱线高度、对应二维场值共同更新
invariant: 频率位置、相位、坐标轴、色标
exit_state: 振幅变为 h1*a1、h2*a2
visible_inference: 滤波改变成分的相对振幅
```

共同驱动的多视图可以同时变化，先说明它们的对应关系；避免同时引入两个独立难点。无关对象降低亮度或移除。主对象、上下文与网格使用不同亮度，透明度以实际可读性为准。

## 连续性与公式

- 先展示一个样本怎样操作，再扫描或复制到整体，避免直接出现完成图。
- 同一对象跨镜头保留身份、颜色或空间参照；连续推导用变换桥接。话题切换可切镜，不为转场保留无关对象。
- 将公式拆为语义单元，预先标出真实映射。同字形不一定同含义，不能只依靠自动字符匹配。
- 看过程时减少新文字；读式时暂停。长段静止若没有读图目的，拆句、删减旁白或补上缺失的操作。
- 非线性调色、逐帧自动归一化可能掩盖倍乘。解释数值操作时使用固定色标并说明单位。

## Manim 中的实现

| 目的 | 可用方式 |
|---|---|
| 联动参数 | `ValueTracker` + updater |
| 追踪贡献来源 | `TransformFromCopy`、`ReplacementTransform`，随后呈现实际计算结果 |
| 逐项构造 | `LaggedStart`、`Create`，顺序对应旁白 |
| 语义公式变化 | 分组 `MathTex` + `TransformMatchingTex`；或分组数学 SVG + 显式映射 |
| 连续结果场 | 固定采样网格从同一状态求值，更新像素或已有网格 |
| 局部放大 | `MovingCameraScene`，保留回到全图的参照 |

`Transform` 负责视觉插值，不自动保证中间帧满足约束。参数曲线、约束几何、频率与积分演变应从参数求值；版式迁移或对象身份延续可采用形变。

[联动模板](../assets/manim_motion_template.py) 用同一参数更新曲线、振幅柱和条纹；不需 TeX，可独立渲染。它示范联动结构，不代表真实成像模型。

## 先试最难的一镜

全片制作前，先低清渲染最关键的操作。若仅凭画面无法认出刚才发生了什么，调整状态和对应关系，再扩充场景与配音。

验收：起点、中间、终点数值与几何一致；静音能辨源对象、操作与结果；播放关键区间核对指代、动作与停顿。抽帧只支持部分检查，像素发生变化不能证明讲解有效。可记录关键操作的时间段与截图供比较，不把运动比例或动画种数当作教学质量分数。
