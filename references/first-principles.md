# 从第一性原理组织讲解

本方法用于设计新讲解或修订概念堆叠的讲稿。起点是当前问题所需、观众能够理解的基本事实与约束；终点是观众能自己推出关系并解释变化。

## 先搭概念依赖，再选叙事路径

先问：观众要做什么判断？手里能看到什么？哪些条件暂时成立？一个最简单的办法为什么足够或不足？需要增加什么信息才能继续？

用这些答案画出概念依赖。例如分类评价可以从“对象与真实结果 → 被选中的集合 → 交集与计数 → 不同分母 → 指标 → 阈值权衡”展开。依赖图是设计工具，不必整张先给观众看。

选择适合主题的起点：

- 数学：定义、已知关系与明确假设，逐步推出目标关系。
- 算法：输入、允许的操作、目标与资源约束，展示简单方案何时遇到障碍。
- 科研：测量与决策需求、观测事实、时间与信息边界，提出可检验解释。经验事实不能靠动画推成定律。

起点相对于受众已有知识。解释EEG疗效评价通常无需从神经细胞开始；解释EEG信号起源则可能需要。开头可以预览结果，但不要提前塞入整套尚未解释的术语。

## 一个概念怎样在画面里出现

建议采用“问题 → 预测 → 操作 → 观察 → 必要关系 → 命名 → 新情况检验”的节奏，按内容省略无帮助的环节。

1. 给出一个可以回答的具体问题，让观众有机会猜结果。
2. 保留对象身份和参照，只改变当前需要检验的条件。
3. 显示发生了什么：计数、距离、交集、误差或信息缺失。
4. 把观察压缩成关系。等式的每一项能指回对象；关键推导步骤可见。
5. 最后给关系命名，再用新例子检验解释是否可迁移。

让动画执行推理：集合筛选揭示分母，投影揭示信息损失，滑动阈值揭示选择权衡，重复抽样揭示不稳定性。淡入文字只负责引导与命名。类比可以帮助进入问题，但应回到实际对象，指出成立关系与省略条件。

## EEG疗效预测：一段可复用的推导分镜

以下20位患者和分数均为教学构造。8人实际响应，12人未响应。颜色表示真实结局；框表示模型推荐的集合，两种含义始终分开。

| 推进 | 字幕或讲稿 | 画面与推理 |
|---|---|---|
| 建立决策 | 治疗前，我们希望圈出更可能有效的人。怎样判断这个圈有用？ | 20个患者点先出现，标出治疗前输入与事后结局；评价时才揭示真实结局 |
| 给出参照 | 不用EEG，随机圈人，长期看每10人约4人有效。 | 数出全体8/20，建立40%基础率；说明这是期望，不保证每次恰好4人 |
| 检验选择 | 模型圈了6人，其中4人有效。圈里有多可靠？ | 选中框内4个响应者、2个未响应者；先数4/6，再命名PPV≈66.7% |
| 暴露缺口 | 圈里可靠，还不能告诉我们漏掉多少有效的人。 | 高亮全体8个响应者，其中4个在框外；先数4/8，再命名Sensitivity=50% |
| 引出权衡 | 如果只圈最有把握的2人，会发生什么？ | 保留20人身份，收紧阈值；框内2人全有效，PPV=100%，但Sensitivity=25%；先留预测停顿 |
| 归一化 | 原来40%有效，现在圈里66.7%有效，提高到原来的多少？ | 从两个比例得到66.7%/40%≈1.667，命名nPPV≈166.7%；基础率来自评价人群 |
| 回到任务 | 该圈多大，取决于我们能接受多少漏掉的人。 | 显示灵敏度约束与对应工作点；说明指标选择依赖用途，不能由数学单独决定 |

这里“漏掉有效的人”用于解释计数；模型建议的治疗是否改变患者结局，需要额外治疗比较证据。

AUC可以接在上述问题之后：把所有阈值汇总，能否评价排序？先取一个响应者与一个未响应者，比较谁排前面；再遍历所有配对，得到排序概率解释。随后展示全局排序与局部工作点可能给出不同判断。不要直接先报AUC定义。

患者分组也从信息推演：同一人的多个窗口带有共同特征；随机拆窗口可能使模型在测试时遇到已见过的人。先画患者与窗口的来源关系，再推到“新患者评价需要患者隔离”，最后引入Group CV名称。

## 审稿时实际改什么

如果讲稿连续解释多个术语，选一个决策、固定例子，把术语放回它被需要的位置。如果只展示结论，为关键步骤增加一次操作或反例。如果观众只能复述公式，增加一个新数值或新条件，让其先预测再核对。

第一性原理解释成立的标志：观众能说出起点、关系为何需要、条件变了结果怎样变。无需为了制造悬念让每段都失败一次，也无需逐段从最底层重新讲起。
